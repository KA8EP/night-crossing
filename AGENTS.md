# Правила проекта

- Стек: Vite + TypeScript + Three.js (без тяжёлых внешних 3D-моделей, вся графика — процедурный Low-Poly из геометрических примитивов).
- Архитектура: Разделяй код на модули (`src/entities/`, `src/systems/`, `src/ui/`). Не пиши всю игру в одном файле.
- Экономия контекста: При правках изменяй только нужные функции или модули, не переписывай файлы целиком без необходимости.
- Визуальный стиль: Тёмная вечерняя атмосфера мегаполиса, мягкие тени, контрастные цвета (синий спецназ, оранжевые гражданские, красный/фиолетовый суперзлодей).
